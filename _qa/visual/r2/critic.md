# 第二輪盲審紀錄

評審：獨立的 `claude -p`（只給 6 張截圖路徑與目標畫面描述，不給程式碼或推理），在 repo 外的暫存目錄執行。
評審提示詞見 _qa/visual/r2/critic-prompt.txt。

## 第 1 輪（截圖：_qa/visual/r2/round1/）

## 總評
整體色調、逆光霧氣和楓林走廊的構圖已經有電影感的雛形，但目標裡最重要的幾個光影元素都沒做出來：光柱、灰塵、金色光點、葉子逆光透紅、樹冠內部偏暗。現在的許願葉是約 70 片同款的平面發光貼紙，數量太多、到處都是，蓋住了標題，也和 3D 場景的質感對不上。葉片上有網點／抖動圖樣，前景楓枝的景深模糊變成馬賽克，這兩個算圖瑕疵一眼就看得到，讓畫面看起來不像真實拍攝。

## 缺陷清單
- [major] 1/2/4/6 — 樹冠葉片和地面暗部上有規則的網點／方格抖動圖樣，看起來像 alpha hash 或 dither 沒有被解析掉。例子：01 左上樹冠 (≈420,320)、04 整個樹冠每片葉子、06 左側地面陰影 (≈0–400, 1300–1500)。→ 改用 alpha-to-coverage 或 TAA 解析，或改回 alpha test 並加 MSAA；陰影改用 PCF/PCSS 柔化，不要靠抖動。
- [major] 5（1/2 也看得到）— 右上前景楓枝的景深模糊變成明顯的方塊馬賽克 (≈1520–1920, 30–260)，看起來是低解析度 buffer 用最近鄰放大。→ 模糊 buffer 用雙線性取樣再做多 tap 的 bokeh 或高斯模糊，或者直接用預先模糊好的貼圖。
- [major] 1/2/6 — 許願葉擋住標題：01 有葉子壓在「楓」左上 (≈730,500) 和「季」下方；02 有一片黃葉正好蓋在「SEASON」上 (≈1050,700)；06 的「MAPLE SEASON」整行被 4–5 片發光葉遮住。→ 在標題的螢幕區域設排除區，或讓許願葉在標題後方淡出、降低透明度。
- [major] 1/2 — 許願葉數量太多（約 30 片以上同時在畫面中），大小、亮度和描邊都一樣，畫面像撒滿了貼紙。02 剛留言、已經落地停好的那一片，在畫面上和其他許願葉分不出來，看不到「新的這片」在哪裡。→ 新留言的許願葉要有專屬強調，例如較大的尺寸、脈動光暈、光點拖尾，或者讓鏡頭推近；同時降低常駐許願葉的密度和亮度，或依距離分級。
- [major] 1/2/5/6 — 許願葉是平面描邊的 emoji 風格 billboard，沒有透視、沒有厚度，也沒有受光，和 3D 楓葉的材質不一致。02 裡「停好」的葉子仍然直立浮在半空 (≈1010,920；1630,990)，沒有平躺在地面上。05 中景的幾片 (≈640,320；1290,370) 也懸在地面上方。→ 落地後讓葉子貼著地面平躺並對齊法線，改用帶葉脈的 3D 葉片網格搭配自發光，再把光暈收斂一點。
- [major] 1/2/4 — 看不到光柱和光束裡的灰塵：01/02 只有左上太陽附近有極淡的斜向亮帶，04 朝太陽仰望卻完全看不到太陽和光柱。金色閃爍光點也只有零星幾個像素。→ 加強 volumetric 或 screen-space god rays 的強度和遮擋對比，在光束體積內加入少量灰塵粒子；04 的機位要讓太陽留在畫面裡或剛好在畫面邊緣。
- [major] 4 — 樹冠葉子是正面受光的均勻飽和紅，沒有逆光透紅的漸層，樹冠內部也沒有變暗；樹冠很稀疏，大片偏紫藍的天空直接露出來，色溫和其他截圖的暖色霧氣衝突。→ 葉片加 subsurface 或 transmission 項（背光時透出橘紅），加上依樹冠深度計算的 AO 讓內部變暗，並把天空色統一成暖色漸層。
- [major] 1/5/6 — 地面上的落葉稀疏，而且都是平貼的小片，沒有成堆；樹根旁也沒有堆積。地面看起來像龜裂泥地加重複石紋 (05 中下方)，不像林地。→ 在樹根和陰影處撒高密度葉堆（instanced 並稍微隆起），提高地面落葉的覆蓋率，減少地表底材外露。
- [minor] 5 — 光束打到地面的地方出現垂直條紋和色帶 (≈800–1200, 300–450)，看起來像 ray march 的步數不足。→ 增加步數並加 blue-noise jitter，再做時間性累積。
- [minor] 4 — 底部說明文字「點一片發光的楓葉，讀讀別人的願望」被樹枝穿過 (≈1050–1150,1180)，可讀性下降。→ UI 區域底下加一層淡的暗角或文字陰影。
- [minor] 4 — 有兩片許願葉卡在樹冠和枝幹之間，和樹枝互相穿插 (≈1450,720；990,940)。→ 生成和飄落時避開樹冠碰撞體。
- [minor] 3 — 卡片左右兩側邊緣露出沒有被模糊的灰色鋸齒狀物體 (≈700,580；1290,540–640)，看起來是被選中的許願葉或描邊殘留在模糊層之上。卡片下半部也大片留白，卡片裡沒有呈現那片許願葉本身。→ 檢查模糊遮罩的圖層順序，被選中的葉片要嘛清楚呈現，要嘛完全隱藏；卡片版面加入葉片圖示，收緊留白。
- [minor] 2 — 太陽附近的葉緣出現白色鋸齒狀亮邊和閃爍 (≈530–620,150–200)，左中有一片橘色葉子被異常拉長成條狀 (≈230–290,770–800)。→ bloom 前先夾住過亮的像素（firefly clamp）；檢查葉片的動態變形或 motion stretch。
- [minor] 1/2/6 — 樹木模型重複度高，兩排樹的形狀和間距幾乎一樣，像果園。→ 增加樹形變體，加入隨機旋轉、縮放和位置偏移。
- [nit] 6 — 太陽被切在左邊緣，上半部是大片空白天空；左上那片放大的近景葉子沒有景深模糊，顯得突兀。前景楓枝在低畫質下沒有模糊，看起來像貼上去的剪影。→ 手機版重新構圖，把地平線往上移；低畫質至少保留一個便宜的模糊。

最高嚴重度：major

## 第 2 輪（截圖：_qa/visual/r2/round2/）

## 總評
整體色調與構圖已經有秋日逆光的電影感：01、02 的左上主光、霧中漸層的樹列、05 右側的光柱都成立。主要失分在三處：
- 許願葉數量太多、都正對鏡頭懸在半空，像貼紙，搶走畫面主體。
- 樹冠是硬邊的平面葉片，沒有逆光透紅，內部也沒有暗部。
- 地面大多是裸露泥地，看不到落葉堆，天空還有橫向條紋。

## 缺陷清單
- `[major]` 01/02/06 — 許願葉一次出現約 25～30 片，都是同尺寸、同光暈、正對鏡頭的平面向量圖示。右側樹列（01 約 x1500–1800、y550–1000）擠成一團，懸在樹幹半腰。和 3D 寫實的畫風脫節，畫面變得雜亂 → 同時顯示的數量壓到 8～12 片並做遠近層次；遠處的縮小並降低光暈；改用有厚度的 3D 葉片，跟著畫面一起受光，不要整片正對鏡頭。
- `[major]` 02 — 剛留言、「停好」的許願葉認不出是哪一片。中下方那片大黃葉（約 x1070、y910）仍直立懸在離地約半個樹幹高的地方，沒有接觸地面，也沒有接觸陰影 → 新葉落地後平躺貼地並加接觸陰影；新葉給 2～3 秒脈動光或獨立顏色，和既有的許願葉區隔。
- `[major]` 04 — 朝太陽仰拍的鏡頭裡看不到太陽，也沒有葉縫光束。樹冠整體是均勻飽和的正紅，葉片像紙片剪影、硬邊。側面朝鏡頭的葉片變成大量黑色細刺（約 x1100–1550、y100–700）。看不到逆光透紅，冠內也沒有暗部 → 加入透光（subsurface／transmission，依太陽方向提亮葉片背光面）、冠內環境遮蔽（AO）讓內部變暗、葉片 alpha-to-coverage 抗鋸齒；這個角度要讓太陽或光暈出現在葉縫間。
- `[major]` 01/02/04/05 — 地面大多是裂紋泥土的質感，落葉稀疏、平貼在地面，看不到「落葉成堆」。樹根處沒有落葉堆積 → 樹根周圍與路邊加落葉堆（instanced 疊層並帶一點高度），提高近景落葉密度。
- `[major]` 03 — 卡片左右邊緣露出淺色尖刺狀殘影（約 x700、y570，以及 x1290–1300、y550–600），像是被選中的葉片從卡片後方穿出 → 打開卡片時隱藏或淡出被選中的葉片，或把它移到模糊層之下。
- `[minor]` 01/02 — 上方天空（約 x700–1500、y0–300）有一道道橫向條紋，看起來像色階斷層，不像光束；太陽圓盤（約 x600、y160）過曝成硬邊白點 → 光束改成從太陽放射的方向，並加 dithering；太陽做 bloom 柔化、降低核心亮度。
- `[minor]` 01/02 — 中景霧太濃。路中央到遠景的樹幾乎被洗白，中段對比不足，「通透感」偏弱 → 降低霧的密度或提高霧的起始距離，保留中景樹幹的暗部輪廓。
- `[minor]` 05 — 兩棵前景樹幹底部平切插進地面，沒有根部張開，像貼上去的（左幹約 y700–740、右幹約 y540）；左幹前還橫過一條深色帶，看不出是根還是陰影 → 加根部膨大與接地 AO，確認那條深色帶的來源。
- `[minor]` 05 — 左側大顆許願葉（約 x180–380、y470–650）壓在樹幹前方、緊貼樹幹，空間關係不明；左緣還有一片紅色許願葉被畫框裁切 → 避免許願葉生成在離鏡頭很近或畫框邊緣的位置。
- `[minor]` 02/06 — 許願葉疊在標題上：02 的紅葉（約 x855、y520）蓋到「楓」字上緣；06 的紅葉（約 x735、y1100）蓋住 MAPLE SEASON 的「ON」 → 在標題的螢幕區域設排除區，不讓許願葉生成或停留。
- `[minor]` 06 — 低畫質模式沒有光柱和灰塵，下半部地面陰影邊緣偏塊狀，地面紋理被拉伸、模糊；太陽被左側樹冠硬切成半圓 → 低畫質至少保留一條便宜的假光柱（加法混合的面片）；陰影改用柔邊。
- `[nit]` 05 — 右側樹幹的剪影邊緣（約 x1450–1550、y0–400）有輕微鋸齒 → 檢查 MSAA／FXAA 是否在後製之後失效。
- `[nit]` 03 — 「關閉」按鈕的黃色 focus ring 和按鈕之間有縫，看起來像雙層外框；卡片下半部左側空白偏多 → focus ring 改用 `outline-offset` 收緊；卡片內距重新排版。
- `[nit]` 06 — 右下的聲音開關緊貼說明文字那一行的右端，底部 UI 佔掉約 18% 高度 → 聲音開關移到右上，或和說明文字錯開高度。

最高嚴重度：major
