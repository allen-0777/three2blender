## 第 1 輪（截圖：_qa/visual/r2/scene/round1/）

**總評**：場景一完整，沒有破圖。場景二的構圖骨架已經和概念圖一致：踏石、木橋、橫向小溪、神木都在，兩側有石燈籠，黃昏與夜晚的燈籠也點亮了。主要差距在神木的分量與造型、午後的光感與飽和度、夜晚缺月光和燈籠照在地上的暖光。另外低多邊形的岩石與地形邊緣，讓畫面離概念圖的油畫式質感有明顯距離。

### 與目標圖的接近程度

- **A（午後）：5/10**。神木只是一根平滑的 Y 字形主幹，沒有板根、苔蘚和粗壯的扭曲枝幹，撐不起「巨大終點」。整體是灰米色霧感，天空偏灰白，看不到概念圖那種從左上射入的強烈金色光柱和飽和的楓紅。
- **B（黃昏）：6/10**。三張裡最接近。粉紫天色、逆光從神木後方透出、燈籠亮起都對。差距在地面幾乎沒有紅葉鋪滿，偏暗土色。水面只有一片白亮反光，看不到楓紅和燈籠的倒影。
- **C（夜晚）：4/10**。深藍天色和星點有了，但沒有月亮，也沒有月光光束。燈籠只有燈窗亮，周圍地面和水面沒有暖色光暈。地面接近全黑，沒有概念圖那種「藍調環境光＋暖色點光」的對比。

### 缺陷清單

- [major] #2/#5/#8：神木造型太單薄。主幹是光滑的 Y 形圓管，分枝是直線段，交接處很硬。根部沒有外擴的板根，也沒有苔蘚。仰望圖（#8）裡枝幹像幾根圓柱插在一起，樹冠稀疏，露出大片天空。→ 加粗並扭曲主幹，加上外擴板根、苔蘚與樹皮凹凸；分枝要有漸細、彎曲和次級分岔；樹冠加密，蓋住上方大部分天空。
- [major] #2/#5：午後的光感和配色偏離 A。天空灰白，畫面被米黃色霧氣均勻壓平，楓紅飽和度不夠，看不到明確的光柱方向。→ 降低遠景霧的密度與亮度；天空改成帶暖色的高光；左上加有方向的 sun shafts；楓葉色相往鮮紅、橘紅推。
- [major] #4/#7-night/#9-night：夜晚沒有月亮和月光，燈籠的光也沒照到環境。燈窗是亮的，但燈籠底下的地面、踏石、橋面都是黑的，水面也沒有暖色倒影（只有右側一小塊亮斑）。→ 右上加月亮和冷色月光（輔光加淡淡的光束）；每座燈籠加一盞照向地面的暖色點光，讓周圍形成光圈；水面反射要能接到燈籠的光。
- [major] #2/#3/#4/#5/#7：岩石是很明顯的低多邊形，面切得很粗，有平面著色，顏色是暗綠黑色，和周圍柔和的材質風格衝突。最明顯的是 #7 右側橋邊那顆大石，以及 #2 橋右下那顆。→ 提高岩石的細分程度，或加法線貼圖與苔蘚、髒污，顏色往灰褐靠，邊緣做圓角。
- [major] #9-afternoon：手機低畫質下，溪水是一條平的褐色帶狀區域，和地面幾乎分不出來，看不出有一條溪。→ 不做環境反射時，至少給一個天空色的固定反射或藍灰色的 Fresnel 漸層，再加上高光波紋，讓水和地面能分開。
- [major] #2/#3/#4：地形後方有一條明顯的高台邊緣。大約在畫面 y≈480–520 的位置，地面在中遠景突然抬起成一個平台，邊緣是一條直線，像桌面的邊。遠景的樹都長在這個平台上。→ 讓地形平緩過渡到遠景，或用霧和植被把這條邊遮掉。
- [major] #2/#3/#5：地面太空、太乾。大部分是光禿的褐土，只有少量紅色落葉。概念圖的地面鋪滿紅葉，溪邊有草和蕨類。→ 加密地面落葉（例如用 instanced 葉片或貼花），溪岸補一些低矮植被。
- [minor] #2/#5/#9：左上角的前景楓枝，葉子是圓鈍的團塊狀（比較像橡樹或色塊），輪廓有鋸齒和像素感，認不出是楓葉。→ 換成有五到七裂尖角的楓葉輪廓；景深模糊要平滑，不要出現階梯狀的像素邊。
- [minor] #2/#3/#7：木橋踏面是一階一階的樓梯狀，橋身很陡、很高，比較像階梯而不是概念圖那種平緩的拱橋或平橋。→ 降低橋的弧度，踏面改成連續的木板。
- [minor] #2/#5：近景兩座燈籠太大、太黑，被畫面邊緣裁掉一半，午後時幾乎是剪影，搶走視線卻沒有細節。概念圖的近景燈籠是完整入鏡、受光的。→ 燈籠往內收或縮小，讓它完整入鏡；補上受光面和苔蘚質感。
- [minor] #2/#3/#5：黑松在左側，扁平的盤狀層次像一把把傘，量感偏重；銀杏只在最右邊露出一小塊。和「右側少量銀杏＋黑松」的規格不符，畫面上的樹種比例也看不太出來。→ 把黑松移到右側，或右側再加一棵；銀杏的黃色要在主畫面內清楚出現一到兩棵。
- [minor] #2/#3/#5：遠景楓樹的造型高度重複，都是同一種「斜幹＋圓冠」，排成一列看得出是複製的。→ 加大縮放、旋轉和造型變體的隨機範圍，或混入另一兩種樹型。
- [minor] #4/#9-night：夜晚許願葉的光暈很大，中央區域幾乎連成一片，壓在標題「楓葉季」周圍（手機版最明顯，標題左右兩側都被光葉包圍），標題可讀性下降。另外樹枝附近有幾團藍白色、霧狀的圓形光斑，看起來像貼圖精靈的邊界。→ 夜晚縮小光暈半徑，或在標題附近降低許願葉光暈的強度；檢查那些藍色霧狀光斑的來源，並把邊緣柔化。
- [minor] #7-afternoon/#7-night：近景有一片許願葉被景深模糊放得非常大（午後在畫面左側佔了大約 1/6 的面積；夜晚則正好壓在標題「葉季」底下），和標題疊在一起。→ 近景許願葉的放大程度要設上限，或在標題的安全區內降低透明度。
- [minor] #3：黃昏水面有一大片均勻的白亮反光（橋左側），沒有楓紅和燈籠的倒影，看起來像過曝的鏡面。→ 降低鏡面高光，讓水面反射帶出天空的粉紫和楓紅。
- [nit] #1/#2：右上角的「場景二」切換鈕在場景一被前景楓枝蓋到一部分，文字貼近右邊緣，看起來被截掉。→ 前景楓枝避開右上 UI 區，或給 UI 加一點底色襯托。
- [nit] #8：仰望神木時，低處的太陽和白霧讓下半部畫面一片灰白，和「午後暖光」不一致。→ 調整太陽高度，或讓天空在這個角度也保持暖色。

最高嚴重度：major

**實作方處理（第 1 → 2 輪）**：
- 神木：樹幹加粗（底部半徑 2.05 m＋板根外擴）、縱向稜線加扭轉與細紋、板根更粗更長、每根小枝多一個葉叢、葉叢半徑加大、葉片數 17k → 26k（high）、青苔範圍加大。
- 午後：霧密度 0.003 → 0.0022、霧色更飽和偏橘、天空下緣偏暖、光柱強度提高。
- 夜晚：月亮移到神木樹冠右側的空隙（右上方一塊天空不種楓樹），月光光束；燈籠照地面的暖光加強成光圈；水面加上燈籠倒影。
- 岩石改成平滑法線（合併頂點後再擾動）、顏色往灰褐、青苔減少。
- 手機（不拍反射）：水面改成「對岸樹林色＋霧色」的近似反射，再加細碎波光。
- 遠景地形的抬升往後移、變緩（消除平台邊）。
- 地上落葉加到場景一的 1.6 倍；溪岸與燈籠腳下加草叢。
- 木橋拱高 0.38 → 0.24 m、木板間隙縮小；近景燈籠往畫面內收；黑松移到右側、銀杏移進主畫面（右側中景）。
- 夜晚許願葉的光暈不再跟著放大（只加強邊緣光）。
- 沒處理：前景楓枝的葉形（是場景一既有的元件，規格要求場景一不動）；QA 鏡位裡近距離許願葉被景深放大（鏡位造成，首頁不會發生）。


## 第 2 輪（截圖：_qa/visual/r2/scene/round2/）

**總評**：場景二的構圖骨架已經對上目標：踏石、木橋、橫向小溪、盡頭神木，加上兩側燈籠，三個時段也切得出明顯不同的氛圍；場景一完整，沒有回歸破圖。最大的差距在神木和幾個主要道具：神木是平滑的低多邊形 Y 字樹幹，看不出「巨大古木」的份量；燈籠、踏石、橋都是素色塑膠質感；午後的飽和度和陽光感明顯不夠。另外，手機低畫質的溪水看起來像沙地，夜晚的星點跑到樹前像在下雪，這兩點會直接誤導觀者。

### 與目標圖的接近程度
- **A（午後）：5/10**。構圖動線對了，但天空是灰米色、霧很重、整體偏淡，缺少 A 那種從左上斜射的強烈金色光柱和高飽和楓紅。神木沒有盤根、樹幹太細，跟背景楓樹差不多大，撐不起視線終點。
- **B（黃昏）：6/10**。三張裡最接近：紫粉天色、逆光光柱和燈籠點亮的感覺都有。差距是燈籠只有窗格自發光，地面沒有暖色光暈；水面也缺少 B 那種成片的橘紅倒影。
- **C（夜晚）：5/10**。深藍天、月亮、許願葉突出這幾點都達成了。但神木樹冠幾乎全黑，C 裡被暖光打亮的紅色樹冠不見了；燈籠周圍沒有光暈；滿畫面的白點讓人以為在下雪。

### 缺陷清單
- [major] #9 手機午後 — 溪水（約 y 1250–1420 那條橫帶）是米黃色帶條紋的平面，看起來像沙地或沙丘，認不出是水；手機夜晚的溪水則是淡藍白色平面，像冰或積雪 → 低畫質不做反射時，至少給暗色、帶天空色漸層的基底，再加 Fresnel 邊緣亮度和幾片漂葉，讓人一眼看出是水。
- [major] #4、#7(night)、#9(night) — 星點畫在樹冠和樹幹前面：桌面夜晚左上樹冠區、手機夜晚整個樹冠和樹幹周圍都散著白點，看起來像下雪，和秋夜的主題衝突 → 星星只畫在天空層（深度放最遠或用天空遮罩），數量減半；如果是想做螢火蟲或塵粒，改成暖色、帶景深、數量少。
- [major] #2、#3、#4、#8 — 神木造型：主幹是平滑圓柱、一分為二的 Y 形，在 #8 仰視時像彈弓；樹根是平滑的圓錐土丘（#7 右上），沒有盤根和瘤節；樹幹寬度跟背景楓樹差不多，撐不起「巨大」→ 主幹加粗 2–3 倍，分出多條扭轉的主枝，加上板根和露出的根，樹皮加深溝紋法線，樹冠往兩側展開到幾乎蓋滿上半畫面（參考 A 的比例）。
- [major] #4、#7(night)、#9(night) — 夜晚神木樹冠接近全黑或暗紫，楓紅幾乎看不到；C 的主視覺就是被暖光打亮的紅樹冠 → 樹冠加一點暖色的 hemisphere 或 fill light，或讓許願葉和燈籠對附近葉子有局部照明，保留紅色辨識度。
- [major] #2、#5、#6、#7 — 石燈籠是灰色無貼圖的低多邊形，像塑膠模型，沒有石紋和青苔；黃昏和夜晚只有窗格發白光，地面和燈身都沒有暖色光暈（#3 左燈籠、#4 兩側燈籠）→ 加石材貼圖和頂部青苔，點亮時加一顆小範圍暖色點光源或假光暈貼片照地面，窗格顏色改成暖橘，不要純白。
- [major] #2、#7 — 踏石是單色的扁平八角或六角片，邊緣銳利、沒有厚度變化也沒有貼圖，像紙片放在地上；#7 夜晚的踏石反而是米白偏亮，好像自己在發光 → 換不規則的圓潤石頭，帶石紋、微微埋進土裡、周圍長苔；夜晚把反照率壓下來。
- [major] #2 — 午後整體偏灰白：霧太濃、天空沒有藍色，楓紅被洗淡；A 是高飽和的暖金色加清楚的光柱 → 減霧、提高楓葉飽和度，天空右上留一點藍，太陽放左上，光柱更強更集中。
- [minor] 左上前景楓枝（所有桌面和手機截圖）— 葉形是圓鈍的多瓣團塊，比較像橡樹或冬青，不像楓葉；模糊後邊緣還有階梯狀鋸齒（手機最明顯）→ 改用掌狀五到七裂的楓葉剪影，模糊前先做好 alpha 邊緣抗鋸齒。
- [minor] #2、#5 — 右側燈籠被四到五片許願葉疊住（約 x1150–1300, y560–730），燈籠幾乎看不到；兩側許願葉排成兩條直的帶狀，畫面左右兩側顯得擁擠 → 許願葉位置不能動，但可以把右燈籠往外或往後移，或在燈籠附近把許願葉的光暈半徑縮小。
- [minor] #7 — 驗收鏡位裡左側有一片超大的許願葉（約 x280–500, y300–600），#7 黃昏和夜晚則有一片疊在橋和標題「SEASON」上，光暈過曝、蓋住主體 → 許願葉離鏡頭太近時，限制它的螢幕尺寸或淡出光暈。
- [minor] #2、#7 — 背景地面是一大片平面，霧中有明顯的水平邊界（#2 約 y540 一條淡色帶；#7 左側 y260 有平面的硬邊），看起來像一張紙板延伸到地平線 → 遠景加起伏的灌木和樹林層，霧改成用高度漸變遮住接縫。
- [minor] #2、#3 — 木橋踏板等距、沒有貼圖，從正面看像梯子或樓梯；橋和溪岸的接點太平滑，沒有樁或石墩 → 加木紋和磨損，橋頭各放一對石墩，踏板寬度和間距做些變化。
- [minor] 樹種 #2 — 午後的銀杏是橘黃色，和楓樹混在一起分不出來（右側中景）；黑松只在左中和右緣有幾片扁平的深色葉團，存在感很弱 → 銀杏改成偏檸檬的亮黃，葉形做成扇形；黑松加上明顯的層狀針葉和彎曲樹幹，右側至少放一棵輪廓清楚的。
- [minor] #2、#3、#4 前景草叢 — 尖刺狀的單一草叢重複排列，黃昏和夜晚都成了整片黑色鋸齒剪影，搶了前景 → 降低數量、改變草叢大小和顏色，換成柔軟的細草或苔，並混一些落葉。
- [nit] #8 — 樹幹根部下方約 (575, 870) 有一個灰色小三角面，像穿模或遺漏的幾何 → 檢查根部底下的地形或石頭網格。
- [nit] #1、#2、#3 — 右上的「場景一／場景二」「午後／黃昏／夜晚」半透明膠囊在明亮天空和前景樹枝上對比不夠（#1 的「場景二」被樹枝遮住一部分）→ 加深底色或加 backdrop-blur，文字加陰影。
- [nit] #6 — 卡片開啟時背景壓暗得很好；只是點開的那片許願葉沒有被強調，看不出是哪一片 → 被點的那片葉子保持原亮度或加一圈外框光。

**實作方處理（第 2 → 3 輪）**：
- 夜晚的「雪」：是空氣裡的灰塵光點被月光照亮。夜晚把灰塵關到 5%，金色光點留一半像螢火；星星本來就只在天空層。
- 手機水面：近似反射改成暗色的對岸倒影為底、遠處才帶一點天空色，加細碎波光。
